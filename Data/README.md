# Inputs

This directory contains frozen source and derived inputs used by the study. Provider attribution, URLs and third-party terms are listed in [DATA_SOURCES.md](../docs/DATA_SOURCES.md). Third-party data are not covered by the repository's MIT code license.

Retrieve binary and large tabular inputs with `git lfs pull`. Do not replace a frozen input with a newer provider release when reproducing the paper.

The current community-typology table and its hashes are in [results/stage7/2026-10-14/](../results/stage7/2026-10-14/). Full physical-workflow archive dependencies remain documented in [FINAL_REVISION_RUN_SEQUENCE/EXTERNAL_ARCHIVE_MANIFEST.json](../FINAL_REVISION_RUN_SEQUENCE/EXTERNAL_ARCHIVE_MANIFEST.json).
