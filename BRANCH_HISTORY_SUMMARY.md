# Branch Consolidation and Final Scientific Authority

The author adopted the seven-variable P2 model on 2026-10-14. The sole current branch is `publication/p2-seven-variable`; `main` is preserved unchanged at `8525954d943efe9f06c98c51f218568077788b9b`.

## Final Specification

P2 uses Init_Supply, spectral Grid_Impact, Redundancy_HHI, B_Unconstrained, five-policy MeanDelta, FEMA v1.19 SOVI_SCORE and log1p(frozen Population). Squared-distance budgets are (1/9, 1/9, 1/9, 1/6, 1/6, 1/6, 1/6). Saved K3 is primary; K4 is sensitivity only. The cohort contains 2,299 positive-population tracts, including eight zero-housing tracts, representing 9,066,522 residents. All 2,315 tracts remain in the service model. NCV14 is supplementary environmental context, never a fitted primary coordinate.

## Consolidation Rule

All non-main local/origin histories are joined by a history-preserving merge. The approved final working tree takes precedence: experimental five-class, CORE3, eight-variable NCV14/CBM and unapproved GA alternatives are not restored as active models. This is not a claim that every historical file change was adopted. Frozen diagnostic sources remain reachable by their original commits; no histories are rewritten. No collaborator-owned remote is modified.
