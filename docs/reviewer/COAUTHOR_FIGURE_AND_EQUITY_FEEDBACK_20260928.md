# Co-author figure and equity feedback — implementation decision

## Implemented presentation changes

- Source reliability: the dynamic redundancy panel remains the primary candidate; the station map and full-vs-best-path cross-check are Supplement candidates.
- Station reliability map: all Core sources and the seven largest alternative-route-gain stations are labeled with deterministic collision avoidance; colorbars explicitly describe probability/reliability quantities.
- Full-vs-best-path: Panel A uses lower point opacity and Panel B is labeled as substations.
- SCE facility loading: y-axis labels use base station names; marker shape identifies low-side voltage class, preserving multi-facility distinctions without repeating the voltage suffix in every label.
- Capacity sensitivity: Panel A defines D and K explicitly; Panels B/C use point plots with expanded, explicitly labeled y-scales and three-decimal value labels rather than truncated bar charts.
- Efficiency/distribution trade-off: Candidate S18 now compares aggregate population burden against Q4 burden, absolute Q4–Q1 separation, and population-weighted burden Gini using the frozen 2pc50/C57 results for Impact-first, Hospital-first, and Vulnerability-first.

## Not converted into new scientific claims

- Cluster-specific rankings for financial relief, temporary power, repair resources, or housing improvement are not produced. The frozen clusters are descriptive typologies and the model has no intervention-response or cost functions that would support such rankings.
- Low-income and very-low-income restoration times are not reported from the current model. The frozen Stage 7 feature set contains the composite NRI SOVI score but no explicit low-income/very-low-income group variable. Q4 is therefore not relabeled as an income group.

These two suggestions may be discussed as future extensions, but they are not treated as demonstrated results in the current revision.
