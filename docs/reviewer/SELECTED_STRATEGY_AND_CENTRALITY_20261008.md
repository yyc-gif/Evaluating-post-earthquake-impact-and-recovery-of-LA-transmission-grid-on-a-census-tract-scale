# Selected manuscript strategies and network-centrality evidence

The manuscript infrastructure comparison retains Degree-first (number of neighboring stations) and Betweenness-first (intermediary position on shortest network paths). These measure distinct network roles. Centrality-first and Closeness-first are removed only from active manuscript displays; all original experiment results, sequences and trajectories remain in their existing scientific authorities.

The six scheduled manuscript policies are Degree-first, Betweenness-first, Impact-first, Hospital-first, Vulnerability-first and Random. Unconstrained is an idealized reference with no crew competition. Impact-first prioritizes population dependency, Hospital-first prioritizes hospital-linked dependencies, and Vulnerability-first targets the highest social-vulnerability quartile. These represent different objectives.

The protected July visualizer contains a map of the ten stations ranked by network lambda-2 impact, alongside separate centrality distributions and rankings. That map is not a Degree-first or Betweenness-first map. The new supplement evidence will read the saved 92-station degree and betweenness values, without recalculating the network or changing any sequence.
