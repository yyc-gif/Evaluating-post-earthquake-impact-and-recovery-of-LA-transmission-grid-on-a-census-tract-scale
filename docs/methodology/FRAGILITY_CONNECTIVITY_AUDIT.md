# July92 fragility and functional-state audit

This audit compares the protected July commit `182686868cffe962739804f6bc0ccecaed73d601`, the requested revision reference `6f9fb3da89fcfb56677f238a8679866deda854a8`, and the frozen formal inputs. It does not alter any formal realization. Per-station numerical evidence is in `FRAGILITY_DS_PROBABILITY_PARITY.csv`; the same-PGA old/current counterfactual is in `FRAGILITY_PARAMETER_SPLIT_DIAGNOSTIC.csv`.

## What the existing model actually computes

`C257H_Project_Main.sample_damage_states` is unchanged between July and the reference revision. It evaluates four lognormal exceedance CDFs at each fixed station PGA, constructs `P(DS0...DS4) = (1-E1, E1-E2, E2-E3, E3-E4, E4)`, clips negative/out-of-range state probabilities, renormalizes, then draws independent uniforms per station and realization. July `run_stage_1` and revised `run_stage_1_revision` both substitute `mu_DS*_old`/`beta_DS*_old` for Northridge, SanFernando, and LongBeach, and use unsuffixed columns for 2pc50. The revision changed realization identity/stream management and downstream execution, not the fragility equations or the station parameter table. The 92-station `Data/working_area_substations_with_fragility.csv` is byte-identical across the compared commits; the recorded parameter table first entered Git in `df1fc85` (2026-05-20).

The 92-row `Data/Substations_PGA_IDW_CEC_expanded.csv` is also byte-identical between July and the reference revision. The retained raw functionality is DS0=1, DS1=.50, DS2=.09, DS3=.04, DS4=.03; `F=1[f>=.5]` means exactly DS0 or DS1 at t=0. The 100,000-state connectivity analysis is an *additional diagnostic of that existing fragility-plus-topology mechanism*, not a new fragility model. It samples functional masks only, without repairs, crews, GA, or restoration. The frozen formal Monte Carlo already samples DS and propagates the resulting functional masks through the source gate.

## Exact DS2 shortcut check

The earlier independent 100k implementation used `1-E2` as `p_functional`. Algebraically this equals `p_DS0+p_DS1` **only when the four exceedance curves are nested and the production clipping/renormalization has no effect**. Across all 368 frozen station×hazard input combinations, the maximum absolute difference is **4.43699e-6** (Northridge, station `307693`); mean difference there is 4.82281e-8 and one of 92 stations differs above 1e-12. In 2pc50 the maximum is 5.39548e-9, mean 1.21772e-10, four of 92 differ above 1e-12. SanFernando and LongBeach agree to 2.22e-16 with no non-nested exceedance vectors. The five affected combinations arise from crossing exceedance curves at high PGA; production clips and renormalizes the resulting negative DS bin. Thus exact equivalence cannot be claimed.

Only `substation_connectivity_reliability._fragility_probability` was changed for *future independent diagnostics* to call the exact five-state production probability kernel and sum DS0+DS1. Already saved 100k states/statistics and all 4,000 formal physical draws remain untouched; the previously computed 100k estimates are explicitly labeled as based on the former shortcut. A coupling bound from the input probability discrepancies is on the order of a few parts per million, but this is not a claim that every finite-sample statistic is numerically identical.

## Parameter and voltage provenance

The six parameter tuples (low/medium/high × unsuffixed/`_old`) numerically match the **anchored/seismic** and **unanchored/standard** substation rows, respectively, of FEMA's Hazus Earthquake Model Technical Manual, Table 8-29. They are not two demonstrated Hazus vintages. The [FEMA technical manual](https://www.fema.gov/sites/default/files/documents/fema_hazus-earthquake-model-technical-manual-5-1.pdf) is the external methodological source; the project table itself does not record edition, table row, anchorage observation, or a station-specific anchoring survey. The manual also defines low (34.5–150 kV), medium (150–350 kV), and high (>350 kV) substation classes in its inventory description. In the frozen 92 rows, `voltage_for_fragility` is 66/69/115/138 kV for 44 low stations, 230 kV for 46 medium, and 500 kV for two high. All 92 have positive voltage and a class; no fallback class is *used in this frozen domain*. The station inventory's voltage is based on CEC/HIFLD attributes, but the exact code that initially assigned the fragility class and populated the two parameter sets is not retained in this branch. The class-to-tuple association is internally consistent; a facility-level anchorage verification is not established.

The old/current hazard split is already present in the July production code. **Its reason remains unresolved.** The July manuscript cites Hazus/FEMA and states that parameters are from its substation model, but does not disclose that the three historical scenarios use unanchored curves and 2pc50 uses anchored curves. At each hazard's *same PGA*, replacing old by current parameters changes mean station functional probability by +0.07153 (Northridge), +0.03932 (SanFernando), +0.06443 (LongBeach), and +0.00857 (2pc50; counterfactual only). Therefore cross-hazard results cannot be attributed to PGA differences alone. Choosing whether to retain or harmonize the anchorage assumption is a later author decision; it is not changed here and would require a new scientific run if altered.

## Existing uncertainty boundary

Formal realization seeds produce independent per-station DS uniforms conditional on each scenario's fixed 92-station PGA vector, followed by DS-specific duration draws. There is no sampled spatial ground-motion residual field, no epistemic sampling of fragility medians/dispersions, and no separately sampled seismic failure of the 318 transmission edges in the inspected formal path. These are boundaries of the original physical model, not omissions introduced by the connectivity diagnostic. The route-requirement study reads the resulting frozen event trajectories without creating another damage realization.
