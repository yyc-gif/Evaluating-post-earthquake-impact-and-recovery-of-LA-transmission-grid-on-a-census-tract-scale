# CAISO / WECC compatible-case request steps

1. Create the required WECC account and request base-case permissions under the current confidentiality agreement/data-request process.
2. Submit the WECC Base Case Data Request Package with the academic purpose, requested cases/years, users, storage controls and software format needs.
3. Execute the CAISO Regional Transmission NDA and follow CAISO's current submission instructions for secure transmission-planning access.
4. Request a case whose geographic resolution includes usable SCE and, if present, LADWP internal buses; do not assume a WECC/CAISO case resolves LADWP merely because it covers Southern California.
5. Before acceptance as a benchmark, confirm one compatible case contains bus topology, branch endpoints, X/base, ratings, bus P load, generator/import bounds, status, and slack/boundary treatment.
6. Record permitted publication, derivative-output and retention rules before loading the case into the project.

The public WECC case catalog and CAISO planning reports establish availability and access routes only. They are not model inputs.
