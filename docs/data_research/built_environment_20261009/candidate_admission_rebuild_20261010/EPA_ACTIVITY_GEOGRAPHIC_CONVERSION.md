# EPA activity counts converted to study tracts

Official polygon layer: https://geodata.epa.gov/arcgis/rest/services/OA/SmartLocationDatabase/MapServer/7
Method definition: https://nepis.epa.gov/Exe/ZyPURL.cgi?Dockey=P1014W9I.TXT

The actual SLD v3 layer describes 2018 Census block-group polygons. Its misleadingly named GEOID20 alias refers to 2018 block-group identifiers, not 2020 boundaries. Household counts use ACS 2014–2018 and jobs use 2017 LODES. Cached source rows: 6,425; returned polygon donors: 6,421. The 4 missing source records all have zero households and zero jobs; their identifiers and counts are retained in EPA_SOURCE_RECORDS_WITHOUT_DONOR_POLYGON.csv. No positive activity counts were dropped. 2 donor IDs differ from their older GEOID10 identifiers. Numeric counts on every returned donor match the retained source exactly; max differences: {'HH': 0.0, 'E5_Ret': 0.0, 'E5_Off': 0.0, 'E5_Ind': 0.0, 'E5_Svc': 0.0, 'E5_Ent': 0.0, 'TotEmp': 0.0, 'D2A_EPHHM': 4.998929048483092e-10}.

For donor j and target tract t, w_jt = area(donor land intersect target tract) / area(whole donor land). Land removes the retained 2020 Census water polygons. Source and target vintages therefore remain distinct. Allocate household and each of five job-category counts with w_jt, aggregate counts by target GEOID, then calculate -sum(p log p)/log(number of positive activity categories). A single occupied category has entropy zero; zero total activity is undefined. A fixed-log(6) expression is retained only as a definition diagnostic. Source D2A_EPHHM is reproduced on donors with at least two positive categories; max absolute error 5e-10.

This is uniform-within-donor-land count estimation, not observed target-tract activity. No entropy averaging, GEOID-prefix matching, unsupported-area renormalization or target-count imputation occurs. The actual crosswalk has 25,073 intersections; 6,308 donors span multiple target tracts. Donor activity allocated outside the county target universe remains an explicit residual. Count conservation is checked for each category using all county target tracts plus outside-target residuals, before selecting the study universe; it is not a claim that all county activity falls within the 2,315 study tracts.

Any positive intersection counts as a split, including tiny cross-vintage boundary slivers. Only 345 donors have two intersections each at least 1% of donor land; that threshold describes slivers only and changes no weights. Source donor-land summed area exceeds its union by 2,071,493.445 m² (0.019704% of summed donor land). The service polygons therefore are not a perfectly disjoint cadastral truth. Coverage uses union donor land intersecting the identical target land mask, not summed whole-tract donor intersections divided by another mask. EPA_TARGET_LAND_SUPPORT_DIAGNOSTICS.csv retains those support differences. Count conservation confirms arithmetic, not geographic allocation accuracy.

Disposition: CONDITIONAL. This measures household/job activity composition, not parcel land-use composition. Survey error, job geocoding, within-donor nonuniformity, historical vintages and boundary changes are not quantified by geometric coverage. Coverage is not accuracy.
