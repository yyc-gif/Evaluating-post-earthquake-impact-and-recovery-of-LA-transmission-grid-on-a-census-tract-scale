## T1R1C1 / body block 3 | Front matter

Current paper focus. The revision follows one physical-to-community chain: earthquake damage changes station functionality; surviving source paths determine modeled service availability; repair crews restore damaged stations under alternative priority rules; tract-level service and cumulative burden translate those system states into population, critical-service and vulnerability outcomes. The revised analysis emphasizes how restoration objectives redistribute recovery burden across communities. The network model represents service availability and does not constitute a full electrical power-flow model.

## P0010 / body block 13 | 2.1 Utility-compatible tract–substation mapping

2.1 Utility-compatible tract–substation mapping


## P0011 / body block 14 | 2.1 Utility-compatible tract–substation mapping

Main content. Candidate substations are restricted by utility context before distance weighting: SCE-compatible candidates for strict SCE tracts, LADWP-compatible candidates for strict LADWP tracts, and general eligibility for mixed or ambiguous tracts. Effective distance combines tract-to-access geographic distance with network distance through the retained station graph. Inverse-square weights are normalized, weights below 3% are removed, and the retained weights are renormalized.


## P0012 / body block 15 | 2.2 Realization-specific repair execution

2.2 Realization-specific repair execution


## P0013 / body block 16 | 2.2 Realization-specific repair execution

Main content. Every station with DS > 0 becomes a repair task for that realization. Sampled repair duration remains attached to that task. Crew start time includes the crew’s next-available time and directed travel from its current location; completion returns raw station functionality to one and releases the crew at that station. The physical realization is common to every strategy.


## P0014 / body block 17 | 2.3 Source-connected modeled service

2.3 Source-connected modeled service


## P0015 / body block 18 | 2.3 Source-connected modeled service

Main content. A station contributes modeled service when its damage-dependent functionality is above the functional threshold and it has a surviving path to at least one active Core source. The 14 Core nodes are upstream boundary proxies; production analysis does not solve source dispatch, branch flow, voltage, reactive power or load shedding. Station deficit is decomposed into local damage, threshold loss and source-path loss; tract service is the weighted sum across mapped stations and cumulative burden is integrated over the 480 h horizon.

## P0020 / body block 23 | 2.5 Distributional measures

2.5 Distributional measures


## P0021 / body block 24 | 2.5 Distributional measures

Main content. Tracts are grouped into four equal-count social-vulnerability quartiles using the existing SOVI score, with Q4 denoting the highest-vulnerability quartile. The analysis reports population-weighted burden for each quartile, signed and absolute Q4–Q1 separation, population-weighted tract-burden Gini, and mean tract-level paired burden changes between policies. Negative paired burden change means lower burden under the candidate policy.

## P0023 / body block 26 | 2.6 Vulnerability-first priority

Main content. Vulnerability-first scores each station by the Q4 population mapped to it and uses mapped population as the secondary ordering variable. The resulting sequence is fixed before evaluation and uses the same damage, duration, travel and crew realizations as the other policies.


## P0024 / body block 27 | 2.7 SCE planning-capacity sensitivity

2.7 SCE planning-capacity sensitivity


## P0025 / body block 28 | 2.7 SCE planning-capacity sensitivity

Main content. The sensitivity uses documented SCE cumulative demand D and facility loading limit K where a retained station has an unambiguous one-to-one facility interpretation. Nineteen stations meet this criterion; nine multi-facility stations are not aggregated because no official aggregation rule was identified. The post-processing ceiling is applied to frozen trajectories and leaves unsupported stations at baseline. It is a static planning-peak stress test, not an electrical dispatch model.
