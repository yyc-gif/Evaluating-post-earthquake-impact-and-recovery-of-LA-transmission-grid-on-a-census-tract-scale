## P0021 / body block 24 | 2. Corrections required before manuscript sign-off

A. Do not overstate the threshold conclusion


## P0022 / body block 25 | 2. Corrections required before manuscript sign-off

The 0.963 h term measures the direct removal of a station’s residual functionality under the production threshold. The connectivity indicator C also depends on that threshold: excluding an upstream station can create source-path loss elsewhere. Therefore, a small direct-threshold term does not prove that all network effects are independent of threshold assumptions. The formal .05/.50/.75 comparison is the relevant sensitivity evidence; no-threshold positive connectivity is exactly G0 under the current strictly positive residuals. State both facts. No new capacity model is required. [F, E]


## P0023 / body block 26 | 2. Corrections required before manuscript sign-off

B. State the physical assumptions rather than treating diagnostics as validation


## P0024 / body block 27 | 2. Corrections required before manuscript sign-off

For the retained service-access proxy, the 14 Core points are assumed supply-access boundaries; included functional paths are treated as usable without separate flow, overload, voltage or dispatch restrictions. These are applicability assumptions, not measured properties. Source identity records and local facility loading provide context, not proof of sufficient supply. R1-2 can be answered through this explicit scope plus robustness; it cannot be declared physically solved by redundancy metrics. [R, F]
