# Independent Review Protocol

The user-prescribed specifications, saved KMeans settings and prior spatial cases govern this review. The matching local results are reused. Their source package was locally recorded before its fits, not retrospectively presented as a new registration by this independent reviewer. Copied execution receipts identify earlier computations; independent review receipts identify this round.

The independent pass verifies actual inputs, 12 completed specification records, all 20 seeds/cases, train-only scaling, domain budgets, predictions, inertia for new estimators, original HIST labels, all 1,320 model-pair tables and original-unit differences. It verifies the 20 completed coverage predictions without refitting. The archived 80 ACS count replicates are independently converted to shares; regular and boundary-model MOEs are checked against source decisions.

The ACS fixed-centroid 80-replicate response understates uncertainty at boundary estimates whose variance uses a Census model supplement. Therefore this review adds two explicitly nonprobabilistic endpoint stress cases: set all boundary five-plus shares simultaneously to their point-minus-MOE or point-plus-MOE, bounded to [0,1], keep all other inputs/scales/centers fixed, and count prediction changes. This addresses a missing measurement-sensitivity distinction, not variable/weight selection, and performs no new KMeans fitting. These two endpoints do not optimize worst-case labels, define a simultaneous confidence interval, or independently resample physical realizations.

The cross-specification descriptive check compares which group's mean recovery deficit is largest versus which group's mean SOVI is largest within each saved specification. It does not carry raw class IDs across specifications or assert that physical attributes cause recovery outcomes.

No more clustering, GIS extraction, risk definition, k, weight or physical-sample search is authorized by the review. Original protected files/index are checked before and after. Copied source bytes remain individually hashed. Explicit derivative edits preserve committed line endings, include sensitivity evidence despite a parent ignore rule, and refresh local source-discovery paths during the copied tests. These three metadata files are identified in the derivative ledger; scientific values, fit records and source metadata remain byte-identical to their frozen versions. New root recommendation documents are reviewed artifacts, not byte-identical copies of the source narratives. Raw source whitespace is intentionally preserved rather than globally reformatted.

Initial test execution before the new recommendation documents existed passed 12 numerical/source/preservation tests and failed only the required-document existence test. The completed package's final test receipt supersedes that draft-stage result. An initial freeze attempt also required Windows extended-path normalization; it copied no files before correction. These are recorded implementation issues, not hidden scientific reruns or changes to the protected tree.
