# Fixed-k4 spatial validation

Start with STAGE7_K4_DECISION_NOTE.md. Statistical reference is each seed own saved baseline; seed42 is display only. Exactly40 spatial fits, no full-baseline or k-search fits.

SPATIAL_K4_RUNS: overall/training/heldout agreement and exact deletion sets.
SPATIAL_K4_CLUSTER_MATCHING: training-only matching and class-level membership by scope.
SPATIAL_K4_CROSSTABS: all raw overlap cells, including splits/mixtures.
SPATIAL_K4_PROFILE_STABILITY: original-member deletion versus reassigned membership, original-unit profiles.
SMALL_CLUSTER_34_AUDIT: original34 and independently identified EAL smallest group.
run_records: complete saved scalers, centers, feature weights, labels and specs.

Null heldout class metrics mean that class has no members in that scope; null matching is reserved for no training support. No label is assigned to the four unresolved source records. Cluster IDs are arbitrary.
