# Candidate figure caption

**Coverage of tracts with the largest added modeled service deficit.** The analysis covers 2,315 Los Angeles census tracts under the earthquake scenario with a 2% probability of exceedance in 50 years, at the reference restoration resource level. Service deficit is integrated over 480 hours. Baseline deficit is the modeled loss under idealized unconstrained recovery. Added deficit is the difference between total and baseline deficit. Each row ranks the same tracts by added deficit, baseline deficit, and total deficit, then selects the 579 highest values from each ranking. The first row uses the equal mean of five repair priorities for total and added deficit. Each other row uses the total and added deficits for the named priority. **A** shows the share of high added deficit tracts included in each screen. **B** shows the population living in high added deficit tracts that each screen omits. Total deficit contains the added component. The overlap describes rankings within these simulations. [Candidate image](screening_coverage.png)
