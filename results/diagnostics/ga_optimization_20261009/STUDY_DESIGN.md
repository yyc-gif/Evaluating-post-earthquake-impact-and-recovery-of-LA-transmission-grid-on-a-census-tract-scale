# Predeclared GA optimization study

Physical inputs, 64-sample planning objective and all formal authorities remain unchanged. This study uses a new diagnostic namespace. All mechanisms differing from legacy OX/inversion/tournament/archive-only are labeled variants.

1. Observation-only replay: original five 100-generation histories and five each of population-100/500, 1,000-generation histories. Cached objective values are reused only for this parity/reconstruction phase; no replay runtime is treated as a new objective-cost measurement.
2. Screening: 28 controlled configurations, common seeds 42-46, exactly 50,000 distinct evaluations per run. Population 50/100/250/500; crossed population-100/500 mutation .05/.10/.20/.40/.60, tournament 2/3/5, elite count 0/1/3. Crossover .60/.80/.95 by mutation .10/.40 at population 100. Initialization legacy/diversity-aware/quality mixture at population 100/500. This targeted design estimates those interactions; it is not a full factorial or a complete interaction model.
3. Focused follow-up combines lower mutation, explicit elitism and stronger selection at populations 50/100/500, plus a warm-start alternative (eight configurations, five seeds, 50,000 distinct evaluations). These are tested combinations, not inferred continuous response surfaces.
4. Shortlist: original population-100 comparator, best legacy-initialized configuration and strongest alternative by five-seed mean (standard deviation breaks ties). Twenty seeds 42-61 at 100,000 distinct evaluations, with common 50,000 and 100,000 checkpoints. The selection uses planning results only.
5. Operator screening after parameter sensitivity: inversion/swap/insertion/mixed mutation, ordered/cycle/PMX crossover, adaptive mutation and restart variants at the chosen configuration; five seeds each and 50,000 distinct evaluations. Additional replication and 250,000/500,000 checkpoints are allocated to promising configurations.
6. Local search: deterministic swap/insertion/inversion/block neighborhoods around previous and newly found planning candidates, capped budgets and exact accepted-move accounting. Hybrid and tuned-only comparisons use common total evaluation budgets.
7. Generalization: no new physical samples. A predeclared internal split diagnostic uses the existing 64 samples; a tuned-on-all-64 subset stability check is explicitly descriptive. The already inspected 1,000-sample cohort is reused exploratory evaluation, never described as an untouched test set. Final sequences are selected using planning-only criteria and hashed before this evaluation; no evaluation-guided reselection.

Every fresh search has its own exact permutation cache. Distinct counts include the seven reference evaluations and all initialization candidates. At a budget cutting through a generation, best-observed and last complete-generation archive are reported separately. The identical expensive count is a virtual single-run computation budget; no cross-run lookup cache is used in screening. Total attempted calls include duplicate population evaluations. Wall-clock and objective-only time, peak resident memory, diversity and parent frequencies are retained.

Cost pilot: 2,000 exact objectives in 1.711 s (about 0.856 ms each); initial 7,000,000-objective screen is about 100 CPU-minutes for objective work, plus Python/diagnostic/checkpoint cost. Eight isolated jobs run concurrently. A 50-times-attempt safety cap is reported if a configuration cannot reach its distinct budget; incomplete-budget runs will not be represented as equal-budget results.

The previously best planning objective is 33.03813174326729 h; the original Impact-first incumbent is 33.57830255999924 h. Lower loss is better. No configuration will be called globally optimal. Original figure files are protected; all new figures are candidates only.

Budget-extension allocation clarification before operator outcomes: extend the original P100 baseline and lowest 20-seed-mean confirmed configuration to 500,000 distinct queries, five common seeds each. This retains an equal-budget comparator and limits the extra phase to five million queries. Other promising variants retain twenty-seed 100,000-query replication. No evaluation outcomes determine this allocation.
