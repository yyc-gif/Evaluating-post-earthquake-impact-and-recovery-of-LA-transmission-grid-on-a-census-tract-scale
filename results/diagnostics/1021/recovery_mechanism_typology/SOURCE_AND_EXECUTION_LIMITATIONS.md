## New derived measurements

Only Impact-first reference `e` event states are integrated for the new curves.
No functionality threshold, graph connectivity, source reachability, fragility,
repair order or travel result is recalculated. Station-time linear integration
followed by the original normalized dependency mapping equals the tract-time
integral. Summed window deficits reproduce original total deficit with maximum
error6.48e-12h. Initial availability reproduces the original coordinate within
3e-16. An independent integration of the merged mean history agrees as well.

Unconstrained and Random values are previous verified measurements, not newly
invented curves. Random T80 is each tract's median of1,000 realization first-
passage times; every realization reaches80% in this saved case. The older
time when an *average* trajectory reaches80% is a different estimand and is not
substituted. Transfer resource/hazard checks use existing total integral means;
transfer T80 and time-profile distributions were not analyzed or inferred from
those integrals. This bounded source inventory does not establish that every
other possible event archive is absent.

## Registration and computation

There were90 full K-means fits and1,125 refits:900 random and225 spatial. Every
registered K/seed/draw was retained; no smoke-test sample was substituted for
the experiment. Exact settings and133.79-second fitting runtime are recorded in
`ANALYSIS_RUN.json`. PCA component retention was fixed at95% beforehand, not
selected by silhouette. Initial-state sparsity was neither clipped nor jittered.
The seven-coordinate/equal-RQ convention of old P2 was not imported into this
three-mechanism problem; B has exactly three equally budgeted constructs.

No analytical protocol change was made after viewing results. Implementation
issues were limited to resolving one existing LFS object from a Windows extended
cache path, and allowing1e-14 arithmetic rounding when comparing two equivalent
PCA-centering orders. Saved assignments and deterministic fit reconstructions
are checked exactly. The initial source registration script is intentionally
bound to the starting commit; do not rerun it to overwrite the preregistry.

## Reproduction boundary

All compact matrices, preprocessor arrays, fitted labels, split indices, exact
mean station step history, outcome tables and comparison scores are available
in this branch or its unchanged prior packages. A clean clone must fetch their
actual LFS objects. Re-extraction from raw events requires the manifest-bound
local archive, whose absolute path/configuration is recorded; Git delivery does
not claim that this external archive is included. No missing source values are
imputed. No cluster-dependent external empirical evidence was acquired.

Random/split uncertainty is conditional on the frozen simulation realization
set. Geographic leave-cell-out refits are dependent sensitivity experiments;
their15 cells are not15 independent validation regions. Ward and K-means share
Euclidean geometry and source data. Continuous and group benchmarks likewise
share these data. Contradictory policy/hazard findings remain visible.
