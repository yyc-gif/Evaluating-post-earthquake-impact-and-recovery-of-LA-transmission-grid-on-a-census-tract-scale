# Execution and native-size visual review

The protocol was committed/pushed before outcome comparisons. Source extraction
checked eight saved cases and 3,000 exact event-state identities. It was replayed
to include explicit Git-bound legacy-T80/mapping/population source records;
the derived outcome table remained identical to the analysis input hash.
No recovery schedule, damage sample or service state was regenerated.

The full registered analysis ran all 600 K-means fits: K2/K3/K4 for 100 70%
and 100 85% samples without replacement, using the fixed geometry and settings.
All scores, assignments, profile changes and unfavorable repetitions are saved.
The primary outcome definitions, meaningful-difference thresholds, benchmark
settings and 90%/80% descriptive conventions were not changed after results.

The ancillary Impact total-integral descriptor is retained for transparency,
but not treated as an additional confirmatory endpoint. Unconstrained total
integral is a fitting variable and was excluded from evaluated outcomes.

All three actual PDF pages were rendered at 150 dpi at native 7.2-inch width
and inspected. PDFs contain vector artwork (no raster-image objects), have
minimum 7-pt text, and all text stays within page bounds. 300-dpi PNG previews
and PDF-derived inspection previews are supplied. No official artwork is modified.

- 01: all classes, including the 37-member K4 class, remain visible. Points
  are class means; bars are between-tract P10-P90, not uncertainty intervals.
  Numbers identify one-based within-K classes and do not assert nesting.
  The temporal response is the mean of tract realization medians. Profiles
  have explicit hours and reference-policy/resource/scenario headings.
- 02: both sampling fractions and all registered same-size quantile benchmarks
  are visible. The zero line, favorable direction and preregistered MAE margin
  are explicit. The legend was moved away from the additive-model estimates
  after rendered-page inspection; no numerical values were changed.
- 03: all zero-core cases are shown with a small negative plotting margin so
  their markers are not clipped. The ARI ranges and held-out membership-core
  fractions remain distinct; neither is presented as prediction strength or
  independent external validation.

The independent verifier uses the archived centroids and source outcomes, not
new K-means fits, to recalculate all memberships/Jaccards and held-out cluster
scores. It separately reconstructs quantile groups, linear pseudoinverse and
the fixed additive pipeline to check every benchmark. Source and preservation
checks include all 60 previous diagnostic payload hashes, the original worktree
status/index, all 950 protected files and the frozen publication Git tree.
